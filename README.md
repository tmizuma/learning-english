# English for Software Engineers

グローバルチームで複雑なエンジニアリング議論を英語で行うための実践カリキュラム。

## セッション履歴

### [2026-03-20 Unit 1: 提案と意見表明](https://github.com/tmizuma/learning-english/pull/1)

- "I'd suggest we go with X because..." — 丁寧な提案
- "What I have in mind is..." — アイデアを切り出す（後ろは -ing）
- "The trade-off here is..." — トレードオフを説明
- "The main benefit of this approach is..." — メリットを強調
